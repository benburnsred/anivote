# AniVote

Anime community voting prototype with public poll flows and an administrative console.

## Live site

https://benburnsred.github.io/anivote/

## Features

- Weekly, seasonal, and custom polls
- Multi-select voting with ballot review
- Rankings, movement, trends, and comparisons
- Vote history and poll insights
- Admin poll lifecycle and anime eligibility management
- Vote moderation and CSV export
- User administration and issue reports
- Audit log and anti-abuse settings

This prototype stores demo state in browser `localStorage`. Production multi-user voting will require a server-side database and authentication layer.
